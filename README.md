# Quality Control Shiny App

A Shiny application for collecting and analyzing quality control data from multiple colleagues.

## Features
- Data upload interface for colleagues
- Real-time data viewing
- Quality analysis dashboard

## Setup
1. Run `install_packages.R` to install dependencies
2. Run the app with `shiny::runApp()`

## How to Use
1. Go to "Data Upload" tab
2. Upload your quality data file
3. View all data in "View Data" tab
